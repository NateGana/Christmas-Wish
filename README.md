# 🎄 Christmas Wish System

Welcome to the Christmas Wish System! I built this project so we can all share our holiday wishlists and see what everyone else is wishing for this Christmas. Everything you see here was built from scratch by me.

Feel free to pick a username and start dropping your Christmas wishes below. Keep in mind that all wishes posted on this page are completely public, so everyone visiting can see what's on your list!
